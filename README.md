# 방폭박스 현장 3D 분해도

선박 · 해양플랜트 · 화학공장 현장을 분해해 그 안에 설치된 방폭박스(내압형 Ex d · 본질안전 Ex i · 양압형 Ex p)를 찾아가고, 박스를 부품 단위로 분해해 볼 수 있는 웹사이트입니다.

**사이트 보기 → https://ex-box-exploded-view.vercel.app**

- `index.html` 파일 하나로 된 사이트입니다. Three.js(r128)로 부품을 하나하나 직접 3D 모델링했습니다.
- 현장 구성과 박스 설치 위치는 설명을 위한 예시이며, 실제 제품·상표와 관계없습니다.
